Então, esse app aqui é um bingo de palavras que funciona no navegador. Você adiciona as palavras que quiser, seleciona elas na grade e quando consegue 3 em linha você ganha. Tem opção de usar grid 3x3, 4x4 ou 5x5 dependendo de quantas palavras quer. Você pode salvar os bingos que criar, customizar as cores da interface, colocar um som pra tocar quando alguém ganha, e editar praticamente qualquer texto que vê na tela só dando duplo clique. É bem simples mesmo, basicamente isso.
